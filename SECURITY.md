# Security

To report a vulnerability, please **DO NOT** create a public issue, since that may
expose the problem before it can be fixed.

Instead, report it privately to this repository's maintainers:

<https://github.com/cmspeedau/GameDepot/security/advisories/new>

If private reporting is unavailable, contact the repository owner directly through
GitHub rather than by email.

This fork is independent: do **not** send reports to the upstream Drop OSS project
(`security@droposs.org`) — they do not maintain this code and cannot fix it.
